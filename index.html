Conheça sobre 4 animais da fazenda

O que é um cavalo?

O cavalo é um mamífero herbívoro domesticado, usado para transporte, esporte e trabalho.

O que é uma galinha?

A galinha é uma ave domesticada criada para produzir ovos e carne..

O que é uma ovelha?

A ovelha é um mamífero herbívoro criado para produzir lã, leite e carne.

O que é uma vaca?

A vaca é um mamífero herbívoro criado principalmente para produzir leite e carne.
